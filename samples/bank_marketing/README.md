# Bank Marketing

Source: https://archive.ics.uci.edu/dataset/222/bank+marketing

Attribution: S. Moro, P. Rita, P. Cortez. DOI: 10.24432/C5K306. License: CC BY 4.0.

Pre-contact subscription prediction: duration excluded. Random split is an IID benchmark, not a future-campaign backtest.

Run `python run.py` after installing toolbox. Open generated `results/classification/<run>/report.html`. Original CSV and checksum retained; categorical codes converted using source metadata.
