# Statlog (German Credit Data)

Source: https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data

Attribution: Hans Hofmann. DOI: 10.24432/C5NC77. License: CC BY 4.0.

Historical credit-risk benchmark; macro F1 does not implement the original asymmetric cost matrix.

Run `python run.py` after installing toolbox. Open generated `results/classification/<run>/report.html`. Original CSV and checksum retained; categorical codes converted using source metadata.
