# Default of Credit Card Clients

Source: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients

Attribution: I-Cheng Yeh. DOI: 10.24432/C55S3H. License: CC BY 4.0.

Taiwan credit default benchmark. Demographic predictors require review before real lending use.

Run `python run.py` after installing toolbox. Open generated `results/classification/<run>/report.html`. Original CSV and checksum retained; categorical codes converted using source metadata.
